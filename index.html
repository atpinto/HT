The power of a hypothesis test A test of H0: μ = 0, based on the sample mean

How this simulation works

This applet visualises a test of H0: μ = 0 based on the sample mean X̄. The blue curve is the sampling distribution of X̄ under H0: a normal curve with standard error σx/√n, which is why increasing n or decreasing σx makes it narrower and taller. Both curves share one horizontal axis, so their overlap is shown directly.

Type I error (α) — the red tails beyond the rejection thresholds. If H0 is true, this is the probability of wrongly rejecting it. You set it directly with the α slider; the data cannot change it.

The alternative HA — drag the green knob below the axis to set the true mean μA. The pink curve is the same sampling distribution centred there, drawn on the same axis as H0; the grey arrow joining the two peaks measures μA.

Power — the green areas: the probability that a sample mean lands in a rejection region when the true mean really is under HA. Increasing the true difference, n, or α increases power; increasing σx decreases it. The total is labelled on whichever rejection region carries more of it.

Type II error (β) — the blue region: the probability of failing to reject H0 when HA is actually true. Note that β = 1 − power: every sample mean must land in exactly one of the two.

Opacity. The two right-hand sliders fade H0 and HA independently — useful for talking about one curve at a time while the other stays faintly in view. Opacity and the show/hide checkboxes are two views of one setting: sliding a curve to 0% clears its checkbox, and ticking a cleared checkbox returns that curve to 100%.

Sampling experiment. Use Draw 1 / Draw 200 to simulate real samples of size n from the alternative population (or the null one if HA is hidden). Each dot below the axis is one sample mean: red if it lands in a rejection region, blue if not. The running fraction of red dots converges to the theoretical power.

Keyboard. Click the figure once, then use ←/→ to move the alternate mean (hold Shift for fine steps).

Try: set n = 100 with a small difference, then compare with n = 10, to see how sample size trades off against effect size.
